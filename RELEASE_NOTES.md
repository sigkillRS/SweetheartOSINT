# Sweetheart OSINT v1.0.0

Локальное WPF-приложение (.NET 8, x64) для ведения OSINT-проектов. Работает без установки .NET: сборка автономная, single-file.

## Что включено

- Карточки проектов, профиль, источники, галерея изображений и набор инструментов.
- Динамический редактор карты: стикеры, перетаскивание, изменение размера, редактирование текста.
- Картинки внутри стикера: горизонтальная и вертикальная прокрутка, поворот на 90° кнопкой `↻`, удаление `×`.
- Связи стикеров кривыми Безье: создание перетаскиванием кружка «+» на другой стикер, удаление правым кликом по связи.
- Масштаб колесом мыши и кнопками `−` / `＋`, сброс «Вид 1:1», панорама средней кнопкой мыши или `Space` + перетаскивание.
- Переключение языка ввода `RU` / `EN` одним кликом.
- Удаление проекта корзиной при наведении на карточку, с подтверждением.
- Анимация `▶ Пуск`: появление стикеров, печать текста по символам с мигающей кареткой и курсором, несколько курсоров при большом количестве стикеров, добавление картинок, проявление связей, движение камеры и системные звуки. Остановка через `■ Стоп` или `Esc`, после чего состояние проекта восстанавливается из снимка.
- Монохромная чёрно-белая тема, анимированный фон «искажённая сетка», иконка приложения.

## Установка и запуск

1. Скачайте `SweetheartOSINT.exe` из вложений этого релиза.
2. Положите его в отдельную папку и запустите двойным кликом.
3. Рядом с `.exe` появятся папка `Projects` и, после сохранения профиля, файл `profile.json`.

## Сборка из исходников

Проверено на .NET 8 SDK 8.0.428:

```powershell
dotnet build SweetheartOSINT\SweetheartOSINT.csproj -c Release -p:Platform=x64
dotnet publish SweetheartOSINT\SweetheartOSINT.csproj -c Release -p:Platform=x64 -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish\win-x64
```

Сборка проходит с `0 warnings, 0 errors`.
